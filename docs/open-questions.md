# 미정 사항

Figma 화면을 코드로 옮기면서 정하지 못하고 넘어간 것들입니다. 지금 코드는 이 항목들이 정해지지 않아도 동작하지만, 정해지면 표에 적힌 위치를 고쳐야 합니다.

마지막 업데이트: 2026-11-05 (API 연결)

백엔드에 요청했던 `my_role`(#20), `created_at`(#21), `GET /projects/{id}/members`(#22), `GET /auth/me`(#23), `?after_id=`(#24)는 모두 반영되어 연결하였습니다.

## 구현한 UI

사이트 뷰어 페이지(`/projects/[projectId]/viewer`)에서 아래 부품을 조합해 씁니다. 프로젝트, 핀, 수정 요청, 채팅은 백엔드 API에서 받습니다(`views/site-viewer/model/mappers.ts`에서 화면용으로 변환).

| 화면                                     | 코드 위치                  |
| ---------------------------------------- | -------------------------- |
| 사이트 뷰어 페이지 (조합)                | `views/site-viewer`        |
| 프로젝트 공통 레이아웃 (왼쪽 사이드바)   | `app/projects/[projectId]` |
| 왼쪽 사이드바                            | `widgets/sidebar`          |
| 워크스페이스 상단 바                     | `widgets/workspace-header` |
| 화면 크기 전환 (데스크톱/태블릿/모바일)  | `features/switch-device`   |
| 사이트 뷰어 (브라우저 틀, 핀, 하단 툴바) | `widgets/site-viewer`      |
| 오른쪽 채널 패널 (채팅/핀 요청 탭)       | `widgets/side-chat`        |
| 메시지 입력창                            | `features/send-message`    |
| 채팅 메시지 한 줄                        | `entities/message`         |
| 번호 핀, 프로필 핀                       | `entities/pin`             |
| 수정 요청 카드, 상태 배지                | `entities/request`         |
| 프로필 사진                              | `shared/ui/Avatar`         |

## 아키텍처 결정

`CLAUDE.md`의 "결정이 필요한 것"에 있는 항목입니다. 작업이 여기에 걸리면 먼저 팀에 물어봅니다.

| 항목                           | 선택지                                                                                                | 영향받는 곳                                      |
| ------------------------------ | ----------------------------------------------------------------------------------------------------- | ------------------------------------------------ |
| 배포 사이트 미리보기 / 핀 좌표 | 오버레이로 좌표만 저장 / 배포 사이트에 스크립트 삽입 후 `postMessage` / 프록시로 같은 출처에서 띄우기 | 사이트 뷰어, 핀 위치 저장, "위치 확인 필요" 판정 |
| AI 초안 미리보기               | `iframe srcdoc` + `sandbox` 등                                                                        | 초안 생성 페이지                                 |
| 채팅 실시간 방식               | **결정: 3초 polling** (백엔드에 WebSocket/SSE 없음). 채팅, 핀, 수정 요청 모두 `POLLING_INTERVAL_MS`   | `shared/config/polling.ts`, 각 엔티티 `api/`     |
| 인증                           | **결정: JWT Bearer** (백엔드 방식). 토큰은 localStorage, 1시간 만료, 리프레시 없음, 401이면 `/login`  | `shared/api/token.ts`, `features/auth`           |
| 초안 코드 전달                 | GitHub 저장소 생성 / 코드 다운로드                                                                    | 초안 생성 페이지                                 |

## 백엔드 스펙 대기

| 항목              | 지금 처리                                                                          | 정해지면 할 일                                  |
| ----------------- | ---------------------------------------------------------------------------------- | ----------------------------------------------- |
| 수정 요청 상태 색 | enum과 라벨은 `entities/request/model/status.ts`에 정의. 배지는 '미해결' 색 하나뿐 | 상태별 배지 색 추가                             |
| 채팅 답글 여부    | Figma에 답글 스레드가 있어서 `replies`로 표현. 기능 명세의 채팅은 단일 대화방      | 채팅에 답글이 있는지, 핀 코멘트 스레드인지 확인 |
| 마지막 업데이트   | 배포 시각 필드가 없어서 사이트 뷰어의 "마지막 업데이트" 문구를 숨김                | 백엔드에 `deployment_updated_at`이 생기면 연결  |

## 디자인 확인 필요

| 항목                    | 지금 처리                                                                                           |
| ----------------------- | --------------------------------------------------------------------------------------------------- |
| 다른 상태의 배지 색     | Figma에 '미해결'(빨강)만 있음. 다른 상태도 지금은 빨강으로 보임                                     |
| 요청 카드 구분선 너비   | Figma대로 카드 전체가 아닌 278px 고정                                                               |
| 폰트                    | Pretendard, S-Core Dream이 프로젝트에 없어서 기본 폰트로 보임                                       |
| 프로필 사진이 없을 때   | Figma에 없음. 회색 원으로 표시                                                                      |
| 사이드바 메뉴 아이콘    | Figma에서 모두 집 모양. 메뉴별 아이콘 필요                                                          |
| 답글 아바타 파란 테두리 | 역할(개발자) 표시인지 단순 장식인지 확인 필요                                                       |
| 연한 보라색 핀          | 3번 핀만 연한 색. 해결됨/다른 페이지/선택 안 됨 중 무엇인지 확인 필요. 지금은 `muted` 값으로만 표시 |
| 핀의 빨간 점            | 새 답글 알림인지 확인 필요. 지금은 `showBadge` 값으로만 표시                                        |
| 핀 요청 탭 목록         | 오른쪽 패널의 핀 탭 디자인 없음. 요청 카드를 16px 간격으로 나열                                     |
| 메시지 입력창 안내 문구 | Figma에는 "Project Name". 지금은 "메시지를 입력하세요"                                              |
| 채팅 메시지 크기        | 메시지 단독 시안(아바타 52px)과 페이지 시안(48px)이 달라서 페이지 기준으로 맞춤                     |

## 동작이 정해지지 않은 버튼

모양만 있고 눌러도 아무 일도 일어나지 않습니다.

| 버튼          | 위치                          | 확인할 것                                                                                |
| ------------- | ----------------------------- | ---------------------------------------------------------------------------------------- |
| 사이드바 접기 | `widgets/sidebar` 상단 오른쪽 | 접힌 상태 디자인                                                                         |
| 프로젝트 전환 | `widgets/sidebar` 하단        | 프로젝트 목록 드롭다운 디자인                                                            |
| 참여자 ⌄      | `widgets/workspace-header`    | 참여자 목록인지, 초대 기능인지                                                           |
| 공유          | `widgets/workspace-header`    | 프로젝트 링크 공유인지, 개발자 초대인지 (`onShare` props만 있음)                         |
| 뒤로 / 앞으로 | `widgets/site-viewer` 왼쪽 위 | 사이트 미리보기 방식이 정해져야 페이지 이동을 연결할 수 있음                             |
| 핀 클릭       | `widgets/site-viewer`         | 핀 코멘트 스레드를 여는지, 오른쪽 패널을 핀 탭으로 바꾸는지 (`onSelectPin` props만 있음) |

## 프론트에서 임시로 정한 것

나중에 바뀔 수 있습니다.

| 항목             | 내용                                                                                                                                                                    |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 화면 크기 값     | `'desktop' \| 'tablet' \| 'mobile'` (`features/switch-device`). 각 크기의 실제 너비는 미정이라 지금은 바꿔도 뷰어가 그대로임                                            |
| 라우트           | `/projects/[projectId]/viewer`. 사이드바의 초안 생성(`/draft`), 프로젝트 설정(`/settings`) 페이지는 아직 없음                                                           |
| 사이트 영역      | 빈 흰 영역. 핀 좌표는 이 영역 기준 %로 저장. 미리보기 방식이 정해지면 `SiteViewer`의 `children` 자리에 넣음                                                             |
| 핀 추가          | 핀 모드에서 누르면 입력창이 뜨고, 저장하면 `POST /pins`(+ 고객이면 `POST /change-requests`). 미리보기가 없어서 `element_selector`는 `body`, 좌표는 사이트 영역 기준 0~1 |
| 확대/축소        | 50~200%, 10%씩. "화면 맞춤"은 100%로 되돌림. 처음 값은 100% (Figma 예시는 90%)                                                                                          |
| 디자인 토큰 이름 | `globals.css`의 `ink-*`, `surface-*`, `line-*` 등. Figma 변수 이름과 다를 수 있음                                                                                       |
| 프로필 사진      | 외부 URL을 Next 이미지 최적화 없이(`unoptimized`) 그대로 표시. 이미지 호스트가 정해지면 다시 검토                                                                       |
