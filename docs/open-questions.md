# 미정 사항

화면을 코드로 옮기면서 정하지 못했거나 백엔드를 기다리는 것들입니다. 지금 코드는 이 항목들이 정해지지 않아도 동작하지만, 정해지면 표에 적힌 위치를 고쳐야 합니다.

마지막 업데이트: 2026-11-05 (main `7c1ef7c`, demo-design 적용(#49) 이후 화면 기준. 백엔드는 respec-be main `e377d33`)

#49 이전 화면에 있던 왼쪽 사이드바(`widgets/sidebar`), 워크스페이스 헤더(`widgets/workspace-header`)의 공유·참여자 ⌄ 버튼, 확대/축소, 사이트 뷰어의 브라우저 틀(뒤로/앞으로 버튼)은 없어졌습니다. 관련 미정 항목도 지웠습니다.

## 백엔드 미구현 (respec-be main `e377d33`)

| 항목                         | 지금 처리                                                                                                       | 생기면 할 일                                  |
| ---------------------------- | --------------------------------------------------------------------------------------------------------------- | --------------------------------------------- |
| `deployment_updated_at`      | 배포 시각을 몰라서 "마지막 업데이트" 문구를 보여 주지 않음                                                      | 작업 화면, 프로젝트 카드에 표시               |
| 핀 `source` (초안/배포 구분) | 초안에서 찍은 핀과 배포 사이트에서 찍은 핀이 한 목록에 섞임. 핀 번호도 전체 생성 순서                           | 보고 있는 사이트의 핀만 보여 주기             |
| 핀 삭제                      | 삭제 UI 없음. 댓글 수정·삭제(작성자만)는 있음                                                                   | 핀 삭제 버튼과 권한 정하기                    |
| 수정 요청 `pin_id` 필터      | `GET .../change-requests?status=all` 전체를 받아 프론트에서 `pin_id`로 찾음                                     | 핀 하나의 요청만 조회                         |
| 실시간 채널 (WebSocket/SSE)  | 3초 polling                                                                                                     | 채널이 생기면 polling 대신 연결               |
| 파일 업로드                  | 초안 첨부 버튼 숨김(결정). 채팅과 핀 댓글은 텍스트만                                                            | 첨부 UI 다시 검토                             |
| `users.name`                 | 이름 대신 이메일을 보여 줌. 아바타는 이메일 첫 글자                                                             | 이름으로 바꾸기, 회원가입에 이름 칸 추가      |
| 현재 초대 링크 조회 API      | 발급 응답에서만 링크를 볼 수 있음. 다이얼로그를 닫으면 다시 볼 방법이 없어 새로 발급해야 함(이전 링크는 폐기됨) | 다이얼로그를 열 때 현재 링크와 만료 시각 표시 |

이메일 초대도 백엔드에 없어서 초대는 링크 복사만 됩니다.

## 백엔드와 확인한 동작

코드에 맞춰 둔 것들입니다. 백엔드가 바뀌면 같이 고쳐야 합니다.

| 동작                                                                       | 프론트 처리                                                                                                |
| -------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| `invite_url`이 백엔드 주소(`/invitations/accept?token=`)로 옴              | `token`만 꺼내 프론트 `/invite?token=` 링크로 다시 만듦 (`features/invite-developer/model/invite-link.ts`) |
| 없는 토큰은 미리보기에서 `NOT_FOUND`, 수락에서 `INVITATION_INVALID`        | 둘 다 "찾을 수 없는 초대 링크"로 안내 (`views/invite`)                                                     |
| 비활성화한 링크도 `INVITATION_EXPIRED`                                     | 만료와 비활성화를 한 문구로 안내                                                                           |
| 초안 `preview_url`이 `http://`일 수 있고, 미리보기 응답에 CORS 헤더가 없음 | URL은 쓰지 않고 `access` 키만 꺼내, 라우트 핸들러가 `API_BASE_URL`로 주소를 다시 만들어 서버에서 받음      |
| 핀을 만들어도 수정 요청은 자동으로 생기지 않음                             | 고객이면 이어서 `POST .../change-requests`. 실패하면 "핀은 저장했지만 요청 등록 실패" 안내                 |
| 초안도 배포 URL도 없으면 핀 생성이 409                                     | 핀 모드 버튼을 미리 막고 이유를 보여 줌                                                                    |

| 메시지 입력창 안내 문구   | "메시지를 입력하세요"                                                                                          |
| 프로필 사진               | 사진 필드가 없어서 이메일 첫 글자. 상단바 참여자 아바타는 고객 보라, 개발자 검정 바탕                          |
